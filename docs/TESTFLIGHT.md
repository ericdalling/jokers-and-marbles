# TestFlight
Register the existing explicit bundle IDs and separate iOS and tvOS app records in App Store Connect. Configure repository secrets APP_STORE_CONNECT_API_KEY (raw .p8 contents), APP_STORE_CONNECT_KEY_ID, APP_STORE_CONNECT_ISSUER_ID, and repository variable APPLE_TEAM_ID. The team key needs App Manager and cloud distribution signing access. Accept pending Apple agreements.
The workflow runs after successful main push CI and supports manual dispatch on main. Both apps archive and upload independently. It uses unsigned archives and automatic distribution signing at export, adapted from CPAP Sync. If Apple rejects cloud signing, diagnose permissions or configure manual distribution certificates and platform-specific profiles in a follow-up; never commit credentials.
Build numbers use workflow run number and attempt, with a zero middle component; reruns get a new number. Check App Store Connect processing, export compliance and internal tester groups for each app. Upload success alone is not proof of installability. No public release is performed.
